Getting Started

VerScript is built using the GCC compiler. To compile the interpreter, use the provided Make commands:

  • make : Compiles the `verscript` executable.
  • make clean : Removes compilation artifacts to ensure fresh builds.

Variables & I/O

VerScript uses a spaced colon syntax for variable assignment.

name : "World"
x : 42

Output Statements

Use the display keyword to output messages and variables.

display "Hello, " + name
display x

Input Statements

Use the prompt keyword to receive keyboard input.

prompt user_input

Comments

Single-line comments are denoted by !. Any text following it on the same line is ignored.

! This is a single line comment

Multiline comments use !! at the beginning and end of the comment block.

!!
  This is a
  multiline comment
!!

Arithmetic

VerScript supports standard simple arithmetic operations: addition (+), subtraction (-), multiplication (*), and division (/).

Command Attributes

Commands can take attributes like ?color or ?newline=false to modify their behavior.

display "Success: Engine Online!" ?color="green"
display "Loading... " ?newline=false ?color="cyan"

Loops & Iteration

Use python-like indentation with iterate to create loops with specific steps.

iterate count from 1 to 10 step 2
  display "Iteration Step: " + count ?color="cyan"

Exception Handling

VerScript supports do ... unless blocks for exception handling and triggering custom exceptions using throw.

do
  throw DivisionByZeroError ?msg="Division by zero"
unless DivisionByZeroError
  display "Caught Exception: " + error ?color="green"

System Block Operators

Special system blocks like SuppressErrors and CriticalErrors can control execution flow when errors occur.

SuppressErrors
  invalid_val : 10 / 0
  display "Division by zero bypassed cleanly!" ?color="green"
