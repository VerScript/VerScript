VerScript

A custom, lightweight, C-based scripting language.

About VerScript

VerScript is an upcoming high-performance language built with a custom C interpreter using GCC. It focuses on simplicity and ease of use.

Language Grammar & Rules

Variable Assignment

Variables are assigned using spaced colon syntax: variable_name : expression.

x : 42
name : "World"

Output Statements

Output values using the display keyword.

display "Hello, World!"
display x

Input Statements

Take user input using the prompt keyword, which stores keyboard input to a variable.

prompt user_name
display user_name

Comments

Single-line comments start with !. Any text on a line following ! is ignored.

Multi-line comments are enclosed within !! and !!.

! This is a single line comment
x : 10

!!
This is a
multi-line comment
!!

Arithmetic Operations

VerScript supports simple arithmetic operations: addition (+), subtraction (-), multiplication (*), and division (/).

result : 10 + 5 * 2

System Operators

VerScript includes ForceErrors, CriticalErrors, SuppressErrors, and the throw keyword for error handling.

Polyglot Execution

VerScript supports the inject statement for polyglot code injection across 100+ languages and dynamic eval.

inject python
import math
print(math.sqrt(16))
inject_end

Loops and Conditionals

VerScript features loop, iterate, while, and until blocks. You can also specify step constraints via step n.

Dev Environment & Commands

  • Compiler: Uses GCC.
  • Build Interpreter: Run make (produces verscript executable or verscript.exe on Windows).
  • Clean Object Files: Run make clean.
