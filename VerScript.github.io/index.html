Why VerScript?

VerScript is an interpreter-based scripting language, completely written in C from the ground up to ensure maximum efficiency and lightweight performance.

  • High Performance Interpreter built in C: Execute instructions swiftly without unnecessary overhead.
  • Simple and Clean Syntax: Learn in minutes and focus on building instead of fighting the compiler.
  • Robust Error Handling: Take advantage of do ... unless structures and system operators (e.g., ForceErrors, CriticalErrors).
  • Command Attributes: Simple syntactical sugar (?attr="value") for kwargs formatting directly to terminal output.
  • Indentation-Based Scope: Highly readable formatting enforced through block indentations similar to Python.
