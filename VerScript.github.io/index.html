Lightweight C Core

VerScript is built on a minimal C foundation. It includes a custom lexer and interpreter designed for fast tokenization.

Dynamic Types & Expressions

Enjoy dynamic typing with support for strings, integers, and booleans. Effortlessly concatenate variables and evaluate mathematical expressions directly within the language.

🔄 Loops & Iterations

Supports clean indented loop structures (loop n) and variable iteration bounds (iterate i from x to y) compiled and executed on the fly.

🛡️ Exception Handling & Fallbacks

Supports robust try-catch mechanisms with named compiler errors via do-unless [error], as well as condition fallbacks do-unless [bool].

✨ VS#-1B Neural AI Engine

Powered by VS#-1B, a custom 1-Billion Parameter neural architecture designed for real-time code synthesis, automated error repair, and interactive logic explanation.

💬 Multiline Comments (!! ... !!)

Support for block multiline comment structures (!! ... !!) to comment out large code blocks or documentation notes across lines.

⚙️ Command Attributes & Kwargs

Attach optional modifiers and keyword arguments directly to commands using ?attribute (e.g. ?color="green", ?newline=false, ?default="val").
