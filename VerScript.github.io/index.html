The High-Performance Scripting Language

VerScript is an upcoming high-performance, lightweight, C-based scripting language designed for simplicity and speed.

Read Documentation View Source

Why VerScript?

VerScript brings a clean, spaced colon syntax with the power and performance of a custom C interpreter built with GCC.

  • Simple Syntax: Clean variable assignment with variable : expression.
  • Built for Performance: Lightweight C-based interpreter architecture.
  • Familiar Logic: Standard arithmetic, output statements, and comparisons.

Quick Example

! A simple VerScript example
message : "Hello, World!"
display message

count : 10
loop count
    display "Loop iteration!"
