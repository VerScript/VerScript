VerScript

A lightweight, C-based scripting language.

Introduction

VerScript is an upcoming high-performance language. It features a custom, lightweight, C-based interpreter. Its syntax is simple and easy to read, with indentation-sensitive block scoping.

Key Features

Variables

Variable assignment uses a spaced colon syntax.

x : 42
name : "World"

Input and Output

Output statements use display. Input statements use prompt to store keyboard input into variables.

display "Hello, " + name
prompt user_input

Comments

Single-line comments start with !. Multiline comments are enclosed in !! ... !!.

! This is a single-line comment
!!
This is a
multiline comment
!!

Attributes

VerScript supports command attributes like ?color, ?newline, and ?msg for formatting and configuration.

display "Success!" ?color="green"
display "Loading... " ?newline=false

Loops & Iteration

Loops can be executed using loop, while, until, or iterate blocks.

iterate i from 1 to 10 step 2
  display "Iteration: " + i

Exception Handling

VerScript features powerful do ... unless exception handling.

do
  throw DivisionByZeroError ?msg="Division by zero!"
unless DivisionByZeroError
  display "Caught Exception: " + error

System Block Operators

System blocks like SuppressErrors can catch and suppress errors gracefully.

SuppressErrors
  invalid_val : 10 / 0
