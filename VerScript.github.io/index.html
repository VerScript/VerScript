About VerScript

VerScript is a lightweight, custom scripting language interpreter built with GCC. It is designed to be simple, readable, and highly extensible. Features include dynamic polyglot code injection, multiline comments, and flexible error handling mechanisms.

Explore our documentation to learn more about the syntax, features, and how to get started writing your first VerScript programs.
