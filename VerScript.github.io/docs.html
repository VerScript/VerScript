VerScript Documentation

1. Basic Syntax

VerScript uses a spaced colon syntax for variable assignment, `display` for output, and `prompt` for user input.

! Single-line comment
x : 42
name : "World"
display "Hello, " + name
prompt user_input

2. Multiline Comments

Multiline comments span multiple lines, beginning and ending with `!!`.

!!
This is a multiline comment.
It can span multiple lines.
!!

3. Polyglot Code Injection

VerScript allows injecting code from over 100 languages directly using the `inject` keyword. It also supports dynamic VerScript evaluation.

display "Testing Python Injection"
inject python
  print("Hello from Python!")
  x = 10 + 20
  print(f"Result: {x}")

inject verscript
  display "Nested VerScript Evaluation!"

4. Loops and Step Constraints

VerScript supports `iterate`, `while`, `until`, and `loop` with optional `step` constraints.

iterate i from 1 to 10 step 2
  display i

x : 0
while x < 20 step 5
  x : x + 5
  display x

5. Error Handling

VerScript provides robust error handling with `throw`, `ForceErrors`, `CriticalErrors`, `SuppressErrors`, and the `do-unless` construct.

! Throw a custom error
throw "Something went wrong!"

! Suppress errors in a block
SuppressErrors
  x : 10 / 0 ! Division by zero error is ignored

! do-unless construct for fallbacks
do
  throw "Intentional Error"
unless error == "Intentional Error"
  display "Caught the error!"
