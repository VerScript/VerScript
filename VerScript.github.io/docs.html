Language Features

Variable Assignment

VerScript uses a spaced colon syntax for assignment:

x : 42
name : "World"

Input and Output

Display text or variable values and prompt for input:

display "Enter your name:"
prompt user_name
display "Hello, " + user_name

Command Attributes for display styling:

display "Success!" ?color="green"
display "Loading " ?newline=false

Comments

Single-line comments are prefixed with ! and multi-line comments are enclosed within !! ... !!.

! This is a single-line comment
!!
This is a
multi-line comment
!!

Comparison and Conditionals

Compare variables using standard operators (=, x=, >, <, >=, <=).

If, Else If, and Else blocks evaluate conditionals using Python-style indentation:

if x > 10
  display "x is greater than 10"
else if x = 10
  display "x is exactly 10"
else
  display "x is less than 10"

Loops and Iteration

Iterate ranges or repeat operations with loop, iterate, while, or until.

! Loop 5 times
loop 5
  display "Hello!"

! Iterate with a step
iterate i from 1 to 10 step 2
  display "Value: " + i

! While loop
while x < 5
  x : x + 1

Exception Handling and System Operators

Advanced error mitigation utilizing do ... unless blocks. A global error keyword binds to the caught error context.

do
  throw DivisionByZeroError ?msg="Division by zero"
unless DivisionByZeroError
  display "Caught: " + error

VerScript also comes packed with internal system operators for advanced script-level constraints:

ForceErrors
CriticalErrors
SuppressErrors
