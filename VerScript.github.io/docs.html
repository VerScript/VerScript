Language Features

Variable Assignment

Spaced colon syntax:

x : 42
name : "World"

Input/Output

Display and prompt:

display "message"
prompt user_input

Command Attributes for display:

display "Success!" ?color="green"
display "Loading " ?newline=false

Comments

Single line comments use ! and multiline comments are enclosed in !! ... !!.

Loops

Iterating ranges:

iterate i from 1 to 10 step 2
  display "Value: " + i

Exception Handling

Using do ... unless blocks:

do
  throw DivisionByZeroError ?msg="Division by zero"
unless DivisionByZeroError
  display "Caught: " + error
