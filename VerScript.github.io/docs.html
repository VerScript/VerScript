VerScript Documentation

Welcome to the official documentation for VerScript. VerScript is a custom, lightweight, C-based scripting language.

Language Basics

Variable Assignment

Variables are assigned using spaced colon syntax: variable_name : expression

x : 42
name : "World"

Output Statements

Use the display keyword to print messages or variables.

display "Hello, World!"
display name

Input Statements

Use the prompt keyword to store keyboard input into variables.

prompt user_input
display user_input

Comments

Single-line comments are prefixed with !. Multiline comments are enclosed in !!.

! This is a single-line comment
!!
This is a
multiline comment
!!

Arithmetic

VerScript supports simple arithmetic operations: +, -, *, and /.

result : 10 + 5 * 2

Control Flow

Conditionals

VerScript supports standard conditional structures and comparisons (=, x=, >, <, >=, <=).

if x > 10
    display "x is large"
else if x = 10
    display "x is exactly 10"
else
    display "x is small"

Loops

VerScript supports loop constructs such as loop n and iterate.

loop 5
    display "This prints 5 times"

iterate i from 1 to 5
    display i

Loops and workflows can also be controlled using the step constraint.

Exception Handling

Use do and unless for handling named compiler errors and runtime exceptions.

do
    ! block that might fail
unless ErrorName
    ! fallback logic

System operators such as ForceErrors, CriticalErrors, and SuppressErrors, along with the throw keyword, manage execution flow under error conditions.
